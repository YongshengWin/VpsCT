# 数据与第三方请求

[返回 README](../README.md)

本文描述当前实现；部署者应按自己的使用场景告知账户使用者和分享接收者。

## 1. 控制端存储什么

- `ctlvps.db`：账户、密码哈希、会话、TOTP 与恢复码相关状态、服务器元数据、节点配置和凭据、外部订阅 URL、订阅及分享令牌、流量、访问日志和审计记录。
- `connlog.db`：启用连接日志后接收到的连接元数据及聚合结果，包括来源 IP、目的主机或域名、端口、网络类型、服务与时间。不会主动采集网络传输的正文内容。
- `geo/`：IP 归属地数据库和归属地查询缓存。
- `backups/` 或安装器升级备份目录：相应数据库或整个数据目录的备份；同样包含敏感信息。
- 首次启动的 `setup-token`：创建管理员所需的本地一次性能力令牌，创建成功后失效并删除。

默认保留周期与后台任务以设置页和代码为准：连接原始日志默认 7 天、连接聚合默认 90 天、访问日志默认 30 天；修改保留设置后由定时清理执行。

## 2. 何时访问外部服务

| 功能 | 外部服务及发送内容 |
|---|---|
| 安装和升级控制端 | GitHub Release；下载程序、校验清单和安装脚本 |
| 可选 HTTPS | Caddy 官方软件源；证书机构需要验证配置的域名 |
| 安装服务组件 | sing-box / Snell 的上游下载服务；请求指定版本与架构 |
| 内核版本下拉 | 上游版本信息服务；只查询列表，保存选择后才升级 |
| GeoIP 数据初始化 | ip2region 数据的 jsDelivr / GitHub 镜像；下载 XDB 文件，不上传用户 IP 列表 |
| 在线 GeoIP（默认关闭） | 先尝试太平洋电脑网 IP 查询，失败后尝试 ip-api.com；发送待查询的公网客户端 IP。当前 ip-api 备用入口使用 HTTP |
| agent 诊断 | 公网出口 IP 与 IPv4/IPv6 连通性检测服务，可观察发起请求的 VPS 出口地址 |
| 外部订阅同步 | 管理员配置的来源 URL，包括该 URL 携带的令牌 |
| Telegram（配置后） | 使用配置的 Bot 向指定聊天发送告警或日报，内容可能包含服务器、分享名称和用量 |

在线 GeoIP 必须通过 `CTLVPS_ONLINE_GEOIP=true` 或 `--online-geoip` 主动开启。关闭后不发起新的在线归属地查询，已有本地缓存仍可使用。

## 3. 控制和删除

- 用 `--disable-connlog` 或 `CTLVPS_DISABLE_CONNLOG=true` 关闭控制端的连接日志存储和接收；节点采集由设置和分享的连接日志开关控制。
- 在设置中调整保留周期；暂停或撤销分享不等于删除其历史日志和备份。
- 卸载程序默认应保留数据。彻底清理时需要分别处理控制端数据、手工备份、安装器升级备份、Docker 卷和 VPS 上的 agent 状态。
- 分享给他人的订阅 URL 本身是凭据。截图前应遮挡二维码、完整链接、访问 IP 与节点连接信息。
