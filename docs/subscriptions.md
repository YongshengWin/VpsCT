# 节点、订阅与分享

[返回 README](../README.md) · [网络与中转](network.md) · [隐私说明](privacy.md)

## 1. 节点库与客户端格式

节点库包含已部署节点、导入节点和链式节点。订阅从节点库生成，或转换外部订阅；不提供配置文件上传与托管。旧上传记录保留数据，但不再提供下载。

### 1.1 协议与导出

SSH、WireGuard、Mieru 提供结构化客户端参数编辑。SSH 使用密码或内联私钥，并固定主机公钥；不接受任意本地密钥文件路径或跳过主机校验。WireGuard 支持受限标准配置导入，不执行 PostUp 等脚本。

| 协议 | 当前输出与注意事项 |
|---|---|
| SSH | Mihomo、sing-box outbound；仅 TCP，不生成通用分享 URI |
| WireGuard | Mihomo、sing-box endpoint、可等价表达时的标准 WireGuard 配置；原生客户端运行验收另行记录 |
| Mieru | Mihomo 配置；服务端由 mita 部署，sing-box 不输出不支持的 Mieru 节点 |
| Snell | 按客户端格式输出；Mihomo 排除不支持的高版本及其依赖链，不修改原节点版本 |
| Shadowrocket 的 Snell | 使用原生 password、version 等字段，保留 UDP、复用与链式参数 |
| Shadowrocket 的 VLESS REALITY | 使用原生 pbk、sid、fp 字段 |

协议被过滤时，相应组引用也需要有效；不能靠伪造版本或生成不等价字段让客户端导入。界面只展示该节点可用的配置片段，不为没有通用 URI 的协议生成空二维码。客户端支持范围以相应渲染器和实际验证为准。

### 1.2 外部订阅信息项

上游可能把剩余流量、到期时间等提示伪装成节点。导入与渲染会排除完整匹配的信息标签，旧记录无需删除即可停止进入代理列表；仅名称含类似词语的真实节点仍保留。只有信息项的同步响应不会清空原有真实节点。

## 2. 模板、预设和订阅链接

模板是客户端收到的完整底稿，包含 DNS、代理组与分流规则，一种模板对应一种格式。预设仅覆盖订阅的代理组与规则，两部分应一起选择；不选预设时沿用模板。预设本身不可下载，分享也不使用这两项预设字段。

模板地区标记无匹配节点时，自动生成的空组回退到当前订阅的可用节点；有匹配时仍只选该地区，用户显式指定的 DIRECT 不变。若整个订阅没有可用节点，不能据此保证代理连接可用。

浏览器直接打开订阅链接时显示使用提示，返回 403，响应不缓存，不直接下载配置；显式格式和短链接同样处理。应把链接添加到对应代理客户端。此识别用于区分浏览器导航，不能代替订阅 token 的访问控制；链接仍应作为凭据保管。

## 3. 部署、分享与网络继承

mita 支持自动部署、TCP/UDP 传输、节点计量、凭据轮换与删除。WireGuard 接入采用单用户 Peer；不能将一个私钥当作所有分享的公共模板。

分享目标可以保存监听与出口网络模板。新建专属入口时复制网络设置和固定出口版本；已有入口、重签与恢复不会因模板后来变化自动改线。Snell/mita 继承监听配置仍受独立内核出口限制约束。

分享按各自凭据、用量与有效期管理，计量保持入站加出站，不额外乘二。暂停后的订阅排除相应专属节点，已下载凭据的停止使用还需节点配置实际收敛。保存、配置下发、应用回执和客户端连通是不同阶段。

## 4. 排查与验证

1. 确认客户端格式支持节点协议和版本，更新订阅后检查实际节点列表。
2. 检查模板最终选择的代理组，不能仅以单节点测速成功证明分流正确。
3. 检查订阅中的访问地址；自定义访问地址和继承服务器公网地址的行为不同。
4. 网络绑定或中转异常时，按 [网络指南](network.md) 查看预检、出口版本和应用回执。
5. 分享不可用时同时检查配额、有效期、暂停状态和专属节点应用状态。

公开模板与分享订阅的 ARM64 官方客户端贯通测试见 [验收记录](readiness.md#8-官方内核与公开订阅贯通验证)。该记录不代表所有客户端、任意自定义模板或全部架构均已验收。
