# v0.1.7 发布说明

## 1. 版本范围

本版将多台 VPS 的线路、节点出口、计量、部署及自动化入口整合为可预览、可查询应用状态的流程。默认使用三台线路，也可选择两台，由第二台同时承担中转和落地。落地可选受管、导入或手动节点，用户无需为入口和中转重复部署代理节点。

### 1.1 网络与计量

线路创建支持搜索及快捷筛选；既有 VLESS 等节点可选择出口中转。节点出口、单段端口转发、网卡与流量各有明确入口。新增 NAT 映射、UDP 固定转发会话管理，并完善账期配额公式与最终计量确认。

普通公网机器之间配置转发不会自动产生运营商专线；机器之间的网络、路由和私网授权需要预先准备。导入节点不是受管服务器，面板不能替外部提供方部署服务或开放端口。

### 1.2 部署与兼容

控制端支持 Release 安装器及 Docker Compose。旧 AMD64 版本的网页升级器会检查双架构文件布局，因此本版 AMD64 包保留一个只报错退出的 ARM 停用提示脚本；ARM 二进制和独立发行附件停止分发。Docker 支持持久数据、升级快照和恢复流程；原生 systemd 维护能力与容器能力有区别，按[运维说明](../operations.md)操作。Alpine/OpenRC 支持被控 agent，控制端的原生安装器仍需要 systemd。

修复代理 Slice/cgroup 身份校验、SO_MARK/seccomp 预检、旧日志权限以及可证明不冲突的防火墙规则识别。受限 LXC、缺失可写 cgroup v2 或隔离能力的主机仍可能不满足要求；不能通过关闭保护绕过。

agent 启动官方 sing-box 时固定使用 `GODEBUG=disablethp=1`，处理部分 Linux AMD64 透明大页策略下的额外堆 RSS。该参数由当前官方内核所用的 Go 运行时支持，不修改或重新编译内核，也不改变宿主机全局大页策略；原有 Go 软预算和 cgroup 硬上限保留。升级 agent 并重新应用配置后，由新建代理进程生效。

本版构建使用官方 Go 1.26.9，更新 x/net 0.60.0 和 source-map-js，修复发布扫描发现的标准库、网络及构建依赖漏洞。

### 1.3 AI 与文档

API 提供能力发现、结构化操作契约和工作流，覆盖节点、线路、出口、订阅、分享、NAT 与维护等操作；VpsCT skill 提供部署及结果确认指引。权限、二次认证和主机授权继续生效。新增功能须同步 API、完成条件、恢复行为和说明文档。

面板使用手册提供分层编号章节、左右目录和搜索；README 提供产品概览及完整 4K 虚构数据截图。

## 2. 升级与回退

1. 备份控制端数据库、加密密钥、配置及当前程序；Docker 部署先检查持久卷和快照空间。
2. 使用本版安装器执行更新，或按 Docker 升级流程切换容器。不要将原生安装直接覆盖为容器安装。
3. 数据库从 v0.1.6 的 schema 30 自动迁移至 schema 41；核对管理员、服务器、节点、订阅、分享及历史用量。
4. 仅向 Linux AMD64 受管 VPS 同步本版 agent；ARM 暂停安装与升级。确认实际文件摘要、在线状态及配置应用回执。仅控制端更新不代表新 agent 能力已启用。
5. 用真实客户端验证节点、域名 HTTP/HTTPS、线路和所需 UDP；检查账期与配额设置。
6. 回退时同时恢复升级前程序、数据库、密钥与配置；不要让旧程序读取迁移后的数据库。

内核继续采用管理员选择的官方发行版；不会自行编译 sing-box，也不会因为面板升级静默追最新版本。

## 3. 限制与验收

### 3.1 功能限制

- 面板样式迁移至 Tailwind CSS 4，[浏览器要求](https://tailwindcss.com/docs/upgrade-guide#browser-requirements)为 Safari 16.4+、Chrome 111+ 或 Firefox 128+；旧浏览器需更新后访问。

- SSH 出口只支持 TCP；UDP、SS-2022 和私网目标等组合按[网络限制](../network.md)检查。
- Alpine mieru 需要官方内核、cgroup-skb BPF/bpffs 和完整隔离能力；Snell 不支持 OpenRC。
- 发行支持收敛为 Linux AMD64：控制端、Docker、agent 与校验器不再分发 ARM 附件；历史正式 Release 的独立 ARM 附件撤下。待有真实测试机器并完成验证后再恢复 ARM 支持。
- API 不承诺所有操作通用幂等；以具体契约与工作流完成条件为准。
