# v0.1.5 发布验收清单

## 1. 使用方式

本清单针对未来 v0.1.5，当前未勾选项代表尚未取得最终候选版本的发布证据，不否认已有阶段测试。每项验收记录源码提交、制品摘要、架构、官方内核版本、命令、结果及限制；失败项不得仅凭交叉编译或其他架构通过而关闭。

2026-09-23 已完成本地候选检查，详见验收记录。下方勾选仅表示所述范围通过；AMD64 主要网络场景已由 GitHub runner 补验，最终标签和公开下载仍按发行流程核对。

## 2. 源码与附件

- [x] 确认发行物不含修改版 sing-box、补丁或自编译内核；测试使用已核验的官方包。

- [x] 在 ARM64 隔离环境验证安装、Docker、维护、卸载和失败恢复；两端同机不越界清理。
- [x] schema 11 升至最终 schema，账户、节点、订阅、分享、密钥与历史用量保留。
- [x] 新库默认 1.14.1、旧库空值固定 1.12.14、旧库显式版本保留；重复启动和迁移失败行为正确。
- [ ] 新旧 agent 能力协商及降级拒绝符合已有资源要求；待应用、维护任务和待结算计量在重启后续办。
- [ ] 携带出口、双端中转和固定转发执行升级、退役、卸载及恢复；端口与最后计量只在确认后清理。
- [x] 对应旧程序与配套备份恢复通过，明确恢复导致的数据时间点变化。

## 4. 网络与客户端矩阵

- [x] ARM64 本地与 AMD64 GitHub runner 分别验证主要实际会话，范围见验收记录；不以交叉编译替代。
- [ ] 网卡改名、删除重建、缺卡、采集失败、物理网卡跨重启，以及计费切换、重试去重和拓扑重叠。
- [ ] 按实际开放组合验证监听、直连、SOCKS5、SS-2022、SSH、WireGuard；覆盖地址族、DNS、私网授权撤销和失败阻断。
- [ ] 双端中转覆盖创建、顺序应用、离线、重启、退役、最终计量和端口释放，无直连回退。
- [ ] 固定 TCP 转发覆盖直连域名与传输出口固定 IP、来源和连接限制、修改及删除；确认 UDP 禁用和 TCP 半关闭限制提示。
- [ ] 公开模板与分享订阅验证各支持协议、实际默认分流、暂停过滤、信息伪节点排除及客户端不兼容过滤。
- [ ] 明确 ULA、NAT/MTU、原生 WireGuard 和未覆盖组合的结果；任何缺口在发布说明保留。

## 5. 页面与发布收尾

- [ ] 浏览器验证网络导航、预检、依赖变化后重新预览、应用失败重试、历史与退役记录、明暗主题和窄屏。
- [ ] 验证升级建议关闭偏好、设置页版本状态、选择但未保存不升级、回执匹配后确认。

- [ ] 将待发布标识改为实际日期，记录最终验收和已知限制，按授权范围部署验证。
