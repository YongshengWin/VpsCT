# v0.1.7 打包验收

[返回发布说明](v0.1.7.md)

## 1. 构建对象

候选版本 `v0.1.7`，仓库 `YongshengWin/VpsCT`。最终源码以本版本标签为准，正式附件由发布流程构建并生成 SHA256SUMS。最初的本地候选用于安装与升级回归；安全更新和 Tailwind 4 迁移后须重新通过最终源码及附件门禁，不能沿用旧候选摘要。

## 2. 检查项目

### 2.1 源码检查

运行 `scripts/check.sh`，包含前端测试、类型检查和构建、Go vet/test、API 契约、skill 客户端、AMD64 构建及安装卸载参数测试。依赖声明由 `scripts/third-party.py` 重新生成。安全更新后的完整脚本已通过；认证、数据库、API、GeoIP、维护、agent、更新校验、HTTP、备份和连接日志的 race 检查也已通过。ShellCheck 预检和工作流语法检查通过；生成测试脚本的字面变量和最后参数提取已回归验证。

### 2.2 最终附件检查

执行仅 AMD64 的 `make release`，检查固定版本、仓库、归档结构与 SHA256SUMS。使用最终候选附件进行安装、维护及真实历史网页升级测试；历史程序来自官方 v0.1.6，并逐文件对照官方资产摘要。代理内核来自上游官方 1.14.1，验证摘要后使用。

### 2.3 验收范围

本机容器为 Linux ARM64，AMD64 仅交叉编译。安装测试包含 systemd 替身；维护和历史升级使用隔离 systemd 容器。本地候选已通过安装与 Caddy 分支、卸载 18 场景、维护 12 场景，以及官方 v0.1.6 历史网页升级和原订阅域名 HTTP/HTTPS 流量。正式附件在 Release 工作流再次验证，最终结果以标签 Actions 和 Release 为准；本地候选结果不替代最终附件门禁。

## 3. 公开发行门禁

公开前确认最终提交与附件对应、原生 AMD64 CI、授权测试环境的 HTTPS/初始化/接入，以及公开下载摘要。正式发布后再核对 `latest`。本地打包不会替代这些检查。

## 4. 安全更新与前端迁移

Go 更新至官方 1.26.9，x/net 更新至 0.60.0；govulncheck 未发现可达漏洞。Tailwind CSS 4、tailwind-merge 3 和 source-map-js 更新后 npm audit 为 0 漏洞。迁移修正了工具误改的组件 variant 字段，保留组件参数语义；已实际检查桌面浅色、深色、服务器卡片、表单与下拉框，以及使用手册和 390px 文档目录。浏览器最低要求见发布说明。

原生 CI 曾在 IPv6 UDP 探测的 700ms 收包期限触发超时，本地同阶段通过。生产路径验收探针现使用 2 秒收包预算，保留外层 4 秒进程期限和精确出网地址断言；新增真实回环 SOCKS UDP 测试覆盖 900ms 延迟、静默超时及原始短时限保留。ARM 支持现已暂停，最终 AMD64 CI 结果仍是发布条件。
