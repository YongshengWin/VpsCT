## 1. 对象与结论

2026-09-23 对当时工作区执行本地发布验收。运行源码与测试/构建文件的 SHA256 清单摘要为 `34493d00b9f6965f763c4fdd211ece1c91950475546a3834b4cf1a9506e02933`（清单不含 Markdown 与编译产物）。基线提交为 `b2dc7c3`，包含本次尚未提交的产品改动；候选包使用版本 `v0.1.5`，不是已公开发行物。验证期间新增测试和文档，不改动产品运行逻辑。提交后仍须由最终标签 CI 核对，不能把基线提交号当作完整源码身份。

## 3. 数据迁移、安装与维护

### 3.1 完整旧版数据迁移

新增 `internal/store/release_migration_test.go`，从完整 schema 11 建库并写入管理员、服务器、加密节点凭据、加密订阅 token、分享与流量样本。直接迁移到 schema 30 后再次打开，逐项确认数据和密钥不变、凭据可解密、无外键错误、旧节点不自动绑定网络。

同时验证旧版未选内核时固定 1.12.14，已选 1.13.21 时原样保留。既有测试覆盖新库默认 1.14.1、空值、显式版本及迁移失败原子性。

### 3.2 隔离安装与恢复

- 安装器测试通过首次安装、令牌初始化、双架构 agent 下载、重复安装保护、损坏附件拒绝、更新、降级拒绝、启动失败及加密备份恢复。该夹具的 systemd 为测试替身。
- Caddy 分支通过已有配置保护、官方包安装与配置校验，未签发公网证书。
- 真实 systemd/nftables 卸载测试通过 18 个场景，包含独立 agent 清理、同机两端隔离、默认保留及显式清空数据。
- Dockerfile 构建与首次启动通过，验证非 root、只读容器中的可写数据卷，以及初始化令牌重启后保留。源码 Docker 默认 dev 构建仍不等同于正式 agent 发行分发。
- 从本地 v0.1.4 包实际安装并初始化 schema 11，升级至 v0.1.5/schema 30，管理员保留、初始化保持关闭、加密备份存在。随后恢复旧程序、环境和加密备份，schema 回到 11，原管理员保留，旧服务可启动且初始化仍关闭。可复用夹具为 `scripts/installer-test/upgrade-v014.sh`，仅允许在一次性安装器容器内运行，挂载 `/src`、旧包 `/old-assets` 和候选包 `/assets`。

### 3.3 维护夹具修正

首次维护测试走到 agent 启动失败场景时，旧夹具因缺少能力声明，被生产兼容预检正确拒绝，结果是 `failed` 而非预期的 `rolled_back`。没有放宽产品校验。

夹具现在分别验证不兼容候选在替换前拒绝，以及通过能力声明的候选正常启动失败后回滚。修正后完整重跑通过 12 个场景，包含控制端失败恢复旧程序与旧数据、错误摘要拒绝、agent 正常更新、不兼容拒绝、启动失败回滚、独立卸载回报及控制端卸载收尾。

## 4. 网络与浏览器

### 4.1 官方内核实际会话

使用官方 sing-box 1.14.1 Linux ARM64，归档摘要与缓存的官方 Release 元数据匹配。真实 agent/systemd 测试在隔离网络中执行。

| 场景 | 结果 |
|---|---|
| 托管 SS-2022 双端中转 | API 创建、两端应用、TCP/UDP、服务端先发数据、独立账本、重启续办、顺序退役、最终清理、端口释放与不回退直连通过 |
| 原有内核计量与出站边界 | CI 的 TestKernelNodeAccounting 与 TestKernelEgressBoundary 通过；验证双向字节、节点隔离、规则替换保留计数及节点封禁 |
| 固定 TCP 转发 | API 预览/创建/重试、指定 WAN、独立流量、改监听端口、清理回执后释放旧端口、最终退役结算通过 |
| 公开模板与分享订阅 | SS2022、VLESS Reality、Trojan、AnyTLS、Hysteria2、TUIC、WireGuard 各自 TCP/UDP 与服务端先发通过；暂停分享后排除专属节点 |

复现入口为 `scripts/test-network-systemd-container.sh`，分别设置 `NETWORK_SYSTEMD_CASE=transit-ss2022`、`forward`、`subscriptions`，并提供已校验的 `SINGBOX_BIN`。

### 4.2 浏览器

缓存 Chromium 首次访问本地测试域名返回 `ERR_EMPTY_RESPONSE`；改用本机 Chrome 后通过项目真实浏览器验收。测试使用 Playwright 1.58.2，与本机已有运行环境匹配；未把它描述为 CI 指定版本的运行结果。

通过管理员初始化、服务器创建、节点部署表单、Secure/HttpOnly Cookie、同站与跨站攻击拒绝、CSRF 与 CSP 检查。新增网络导航、无数据状态、已有代理空列表、UDP/TCP+UDP 转发禁用和 390px 无横向溢出检查，已固化在 `scripts/security-browser.mjs`。

这些结果不替代在线 agent 下全部网络表单、深色主题、升级提示关闭偏好和每种故障状态的浏览器矩阵；已有前端单元测试与阶段验证分别作为补充证据。

2026-09-24，发布 PR 的 [GitHub CI](https://github.com/YongshengWin/VpsCT/actions/runs/35946834802) 中 `network` 作业通过。Ubuntu 24.04 AMD64 runner 下载官方 sing-box 1.14.1，并对照官方 Release 元数据 SHA256 校验，随后运行真实 agent、systemd 和隔离网络。
