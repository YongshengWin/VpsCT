# 开源准备与版本验收

[返回 README](../README.md) · [查看发布流程](releasing.md)

记录日期：2026-09-15。仓库：[YongshengWin/VpsCT](https://github.com/YongshengWin/VpsCT)。本文区分准备阶段的历史记录与首版验收范围。

历史验证不能替代后续版本验收。每个版本仍需对最终源码运行检查，实际发布状态以 [Release 页面](https://github.com/YongshengWin/VpsCT/releases) 为准。

## 1. 已完成的工程准备

- 控制端安装器：固定版本 Release 下载、SHA256 校验、amd64 / arm64、专用服务用户、systemd、可选 Caddy、升级前停服备份和失败恢复说明。
- 首次初始化：本地一次性令牌、文件权限、初始化完成后失效、并发请求只能创建一个初始管理员。
- 发布与协作：CI、安全扫描、标签触发 Release 草稿、双架构压缩包、第三方声明、贡献指南、漏洞报告流程、Issue / PR 模板与变更记录。
- 默认隐私：在线 GeoIP 查询关闭，提供连接日志与第三方请求说明。
- 依赖：升级 Go、Vite 与 React Router；修正前端 API 错误消息解析。
- 许可证：维护者确认采用 MIT，版权署名为 alio；根目录 LICENSE、README、前端包及锁文件元数据已同步。
- 仓库命名：维护者确认 GitHub 仓库名为 `VpsCT`；程序、数据目录和服务名称保持兼容现有部署。
